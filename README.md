# Programação Orientada a Objetos em Dream Maker (DM)

## Sobre o projeto

Este repositório contém um pequeno exercício prático de **Programação Orientada a Objetos (POO)** utilizando a linguagem Dream Maker (DM), do BYOND.

O objetivo é estudar e demonstrar conceitos fundamentais da POO por meio de exemplos relacionados a personagens de um universo ninja fictício.

## Conceitos abordados

- **Herança:** utilização de `mob` como tipo base para especializações, como `mob/uchiha` e `mob/senju`.
- **Atributos:** armazenamento de características dos personagens, como HP e chakra.
- **Métodos (procs):** implementação de comportamentos, como receber dano e executar habilidades.
- **Polimorfismo:** utilização de um procedimento comum, `HabilidadeEspecial()`, com implementações diferentes para cada clã.
- **Abstração:** representação de características e comportamentos comuns por meio de um tipo genérico de personagem.

## Tecnologias

- Dream Maker (DM)
- BYOND

## Objetivo de aprendizagem

Este exercício faz parte do meu processo de aprimoramento em lógica de programação e desenvolvimento de software.

A proposta é compreender como organizar código utilizando conceitos de orientação a objetos, explorando a relação entre tipos, atributos, procedimentos e comportamentos específicos.
